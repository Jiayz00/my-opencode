
# 前端优化

## 概述

优化遵循 6 步流程，但更强调第 2 步（基线测量）和第 5 步（本地启动 + 用户验证）。未经测量，绝不优化。

**定位（思想）**：性能是功能，不是优化项（详见 `references/philosophy.md`）。Web Vitals 是**需求指标**——LCP 超过 2.5s 意味着功能不达标，和"按钮点不动"是同等级的功能缺陷。性能预算因此是产品需求的一部分，超预算即功能不完整，应在 CI 中断言。

## 步骤调整

### 第 1 步 — 需求澄清
询问：
- 具体需要改善什么？（加载时间？交互？打包体积？）
- 当前的痛点与目标指标（优先指定 Web Vitals 指标：LCP / CLS / INP / TTFB / 包体积）
- 需要优化的设备/浏览器/网络条件
- 任何约束（不得破坏现有行为）

## Web Vitals 指标清单（量化目标）

| 指标 | 含义 | 良好 | 较差 |
|------|------|------|------|
| LCP | 最大内容绘制（首屏加载感） | < 2.5s | > 4.0s |
| CLS | 累计布局偏移（稳定性） | < 0.1 | > 0.25 |
| INP | 交互到下一次绘制（响应性） | < 200ms | > 500ms |
| TTFB | 首字节时间 | < 800ms | > 1800ms |
| 页面体积 | 单页总传输量 | < 1500KB | > 2500KB |

- 目标版本优先：移动端（4G 网络）跑分低于桌面端，以移动端为准
- 测量工具：Lighthouse（Chrome DevTools / CI）、PageSpeed Insights（远程）、WebPageTest（真实网络条件）、浏览器 Performance 面板、bundle 分析（webpack-bundle-analyzer / vite-bundle-visualizer）

### 第 2 步 — 规格与计划
- **做任何事之前：** 建立基线指标
- 计划必须包含：
  - 当前测量值（附工具/数据）
  - 目标测量值
  - 要尝试的优化方案
  - 每个方案如何验证

### 性能检查清单（基线测量的覆盖范围）

- [ ] 首屏内容不懒加载（above-the-fold 图片/字体立即加载）
- [ ] 离屏内容懒加载（`loading="lazy"`、import-on-visibility）
- [ ] 非关键代码延迟加载（import-on-interaction：弹窗/图表等用户触发时再加载）
- [ ] 无渲染阻塞资源（render-blocking CSS/JS 已拆解或内联关键部分）
- [ ] 关键请求链最短（首屏依赖的请求按需串行，减少关键链）
- [ ] 无 JS 跳转、无大体积 GIF（改用视频/webp 动图）
- [ ] 压缩与缓存已启用（gzip/br、HTTP/2 或 3、长缓存头）
- [ ] 无布局偏移源（图片宽高占位、字体加载不跳动、动态内容占位）
- [ ] 无未使用的大依赖（按需 import、tree-shaking 生效）

### 第 3 步 — 权限门禁
说明："基线为 [指标 A: Xms]。目标为 [指标 A: Yms]。方案：[Z]。是否可以继续？"

### 第 4 步 — 开发
- 一次只做**一个**优化
- 每次优化后：重新测量，与基线对比
- 回退未能改善指标的优化
- 即使失败的尝试也要记录发现

### 第 5 步 — 验收（关键）
1. 启动本地开发服务器
2. 自测所有优化路径
3. 向用户明确确认呈现：
   - 优化前/后指标
   - 改了什么
   - 供用户验证的本地 URL
4. 等待用户通过浏览器检查确认
5. 如果用户要求修改 → 判断问题级别：局部调整返回第 4 步并重新走写入许可；方案问题返回第 2 步；目标变化返回第 1 步

### 第 6 步 — 兼容性 + 性能预算

- 门禁：向用户请求许可
- 本地回归照常；另需确认：
  - 未引入包体积增长（对比 baseline 的 bundle 分析）
  - 未影响其他页面性能（整体 Lighthouse 分数无回退）
- **性能预算（可选，若项目已配置）**：bundle 体积/分数超阈值即 CI 失败；本角色保证改动不超预算

## 常见借口

| 借口 | 现实 |
|------|------|
| "这个优化显然更快" | 明显不是证据。测量前后对比。 |
| "我一次性优化所有东西" | 一次只改一处，否则你不知道哪个有效。 |
| "我的环境里指标看起来不错" | 必须由用户验证。他们的环境可能不同。 |

## 验证清单

- [ ] 基线指标已记录
- [ ] 每项优化都独立测量
- [ ] 优化前/后对比已记录
- [ ] 其他领域无回退
- [ ] 用户已通过本地浏览器检查确认
