# 功能开发 — 后端

## 概述

在构建新的服务端功能时使用本技能。通用 6 步流程仍然适用。本技能为每一步补充后端相关的细节。

## 步骤调整

### 第 1 步 — 需求澄清
具体询问：
- API 风格（REST/GraphQL/gRPC 等）
- 需要的数据模型变更
- 认证/授权需求
- 性能需求（预期吞吐量、延迟）
- 需要遵循的现有模式

### 第 2 步 — 规格与计划
规格必须包含：
- API 端点（方法、路径、请求/响应结构）
- 数据模型 / schema 变更
- 业务逻辑流程
- 错误处理策略
- 校验规则

### 第 3 步 — 权限门禁
使用 `question` 工具请求许可（vibe-core 第 3 步完整流程）："我将通过修改 [文件] 并采用 [方案] 实现 [X]。我可以开始吗？"**未经明确许可不得编写代码。**

### 第 4 步 — 开发
- 契约优先：先定义 API 结构，再实现
- 添加错误处理和输入校验
- 实现的同时编写测试
- 遵循现有的错误处理模式

### 第 5 步 — 验收
- 运行完整测试套件
- 验证 API 响应与规格一致
- 检查错误场景返回正确的状态码
- 验证认证/授权正常工作

## 验证清单

- [ ] 所有端点返回正确的状态码
- [ ] 输入校验能拦截非法数据
- [ ] 在预期的位置强制实施认证/授权
- [ ] 错误响应与现有模式一致
- [ ] 所有测试通过
- [ ] 现有行为未被破坏
